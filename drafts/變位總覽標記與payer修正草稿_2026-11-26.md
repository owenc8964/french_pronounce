## 一、⚠️ 標記標錯格（`verb_forms.html` `cellMark()`）

### 1-1 現行程式（第 956–968 行，節錄）

```js
function cellMark(v, t, i) {
  const f = t.forms[i]; if (f == null || v.imperso) return '';
  const regular = v.grp === '規則樣本';
  switch (t.id) {
    case 'present':
      if (regular) return '';
      if (BIG4.includes(v.inf) && !/ons$/.test(v.pres[3])) return '要背';
      if (!f.startsWith(stemNous(v))) return '詞幹變了';
      if (i === 5 && stemIls(v) !== stemNous(v)) return 'ils 詞幹變了';
      if (i === 4 && !/ez$/.test(f)) return '不是 -ez';
      if (i === 5 && !/ent$/.test(f)) return '不是 -ent';
      return '';
    case 'imparfait':    return v.imp ? `詞幹 ${v.imp}-` : '';
```

**為什麼會標錯**：它用「這格是不是 nous 的詞幹開頭」來判斷。對 -er 拼字會變的動詞，nous 那格**本身就可能是變的那格**（mangeons、déplaçons），拿它當尺就歪了：
- manger：nous 詞幹是 `mange-`，`ils mangent` 的詞幹 `mang-` 跟它不同 → 標到 ils（錯）；真正變的 `nous mangeons` 沒標。
- déplacer：nous 詞幹是 `déplaç-` → 其他五格都「不是 déplaç 開頭」→ 五格全標（正好相反）。
- appeler／rappeler：`appelle` 剛好是 `appel` 開頭 → je／tu／il 沒標，只剩 ils 因為 ils 詞幹 `appell-` ≠ `appel-` 被標到。

### 1-2 建議改法（取代第 956–968 行；第 969 行以後不動）

想法：-er 拼字會變的動詞（`grp === '-er 拼字會變'`），**拿原形去掉 -er ＋ 規則字尾當尺**，跟它不一樣的格就標，標籤寫出到底變了什麼。imparfait 有 `impf` 的動詞同理，拿 nous 詞幹 ＋ 規則字尾當尺。其他動詞維持原本邏輯。

```js
/* 11-26（Q90）：-er 拼字會變的動詞改用「原形去 -er ＋ 規則字尾」當尺——nous 那格本身就可能是變的那格（mangeons、déplaçons），⛔ 不能拿它當尺 */
const ER_END = ['e', 'es', 'e', 'ons', 'ez', 'ent'], IMPF_END = ['ais', 'ais', 'ait', 'ions', 'iez', 'aient'];
function spellNote(reg, f) {
  if (/ge/.test(f) && !/ge/.test(reg)) return 'g → ge（保持 [ʒ]）';
  if (/ç/.test(f) && !/ç/.test(reg)) return 'c → ç（保持 [s]）';
  if (/ç/.test(reg) && !/ç/.test(f)) return 'i 前面不用 ç';
  if (/ge/.test(reg) && !/ge/.test(f)) return 'i 前面不用 e';
  if (/ll/.test(f)) return 'l → ll';
  if (/tt/.test(f)) return 't → tt';
  if (/è/.test(f)) return /é/.test(reg) ? 'é → è' : 'e → è';
  if (/i/.test(f) && /y/.test(reg)) return 'y → i';
  return '拼字變了';
}
function cellMark(v, t, i) {
  const f = t.forms[i]; if (f == null || v.imperso) return '';   /* 無人稱（falloir／pleuvoir）只有 il 一格，沒有 nous 可以比 */
  const regular = v.grp === '規則樣本', spell = v.grp === '-er 拼字會變';
  switch (t.id) {
    case 'present':
      if (regular) return '';
      if (BIG4.includes(v.inf) && !/ons$/.test(v.pres[3])) return '要背';
      if (spell) { const reg = v.inf.slice(0, -2) + ER_END[i]; return f !== reg ? spellNote(reg, f) : ''; }
      if (!f.startsWith(stemNous(v))) return '詞幹變了';
      if (i === 5 && stemIls(v) !== stemNous(v)) return 'ils 詞幹變了';
      if (i === 4 && !/ez$/.test(f)) return '不是 -ez';
      if (i === 5 && !/ent$/.test(f)) return '不是 -ent';
      return '';
    case 'imparfait':
      if (v.impf) { const reg = stemNous(v) + IMPF_END[i]; return f !== reg ? spellNote(reg, f) : ''; }
      return v.imp ? `詞幹 ${v.imp}-` : '';
```

（Q83 原本的提案是針對 manger／déplacer／-eler 寫死；這版改成一條通則，以後再加 -ger／-cer／-eler／-eter 動詞不用再改程式。）
