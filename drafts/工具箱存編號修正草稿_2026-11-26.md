## 結論（先看這段）

1. 兩個同步 key 都會把句型全文送上雲端：`clb7_toolbox_use` 的**鍵名**就是全文、`clb7_toolbox_wpick` 的**值**是全文陣列。只改值不夠——鍵名本身就是外漏。
2. 所以不能「原地改形狀」，要**換新 key**（`clb7_tbx_use`、`clb7_tbx_wpick`），只存編號；舊的兩個 key 在**同步層退休**（sync_supabase.js 加一張 RETIRED 表，跟現有 TOMB 同一個思路）。模擬證明：只在本機刪掉或蓋成 `{}` 都擋不住，另一台的全文會被合併加回來。
3. 寫作頁清單改成 `{cur:{ids:[…], last:時間}}`；清空時寫 `ids:[]`＋新的 last 當 tombstone，⛔ 不用 removeItem。
4. 前提：私人原始檔每條句型／詞彙要先有**永久編號**（像 codex.js 座標，一經指定不重編）。這一步要 Owen 或有權限的 session 在本機私人檔做，我沒讀那個檔，格式**未查證**。

## 三、舊資料怎麼遷移

| 舊資料 | 遷到 | 方式 |
|---|---|---|
| `clb7_toolbox_use`（`'p:'+全文` → `{pick,used,last}`） | `clb7_tbx_use`（`'p:'+編號`） | 同步層先把舊 key 收進本機 `tbxold_use`（第二節 D）。toolbox.js `load()` 成功（已登入、拿得到內容）後跑 `migrate()`：用內容建「全文 → 編號」對照，逐筆搬；同一編號已經有紀錄就 **pick／used／last 各取大**，⛔ 不加總 |
| `clb7_toolbox_wpick`（`[{fr,zh},…]`） | `clb7_tbx_wpick`（`{cur:{ids,last}}`） | 同上收進 `tbxold_wpick`；新 key 還沒有時才搬（已有新清單代表他挑過新的，舊的不要蓋回去），`last` 用遷移當下時間 |
| 對不到編號的（句型改過字、或已刪掉） | 留在本機轉存名 | 不上傳、不刪；在工具箱底部用灰字顯示「有 N 筆舊紀錄對不上」，讓 Owen 決定（⛔ 不要寫成責備句） |

```js
function migrate(){ try{
  var old=JSON.parse(localStorage.getItem('tbxold_use')||'null'); if(!old) return;
  var f2i={}; C.cats.forEach(function(c){ c.items.forEach(function(x){ if(x[6]) f2i[x[1]]=x[6]; }); });
  C.vocab.forEach(function(g){ g.w.forEach(function(x){ if(x.id) f2i[x.fr]=x.id; }); });
  var rec=useRec(), left={}, n=0;
  Object.keys(old).forEach(function(k){ var id=f2i[k.slice(2)], o=old[k]; if(!id){ left[k]=o; return; }
    var nk='p:'+id, r=rec[nk]||{pick:0,used:0,last:0};
    rec[nk]={pick:Math.max(r.pick,o.pick||0), used:Math.max(r.used,o.used||0), last:Math.max(r.last||0,o.last||0)}; n++; });
  if(n) useSave(rec);
  if(Object.keys(left).length) localStorage.setItem('tbxold_use', JSON.stringify(left)); else localStorage.removeItem('tbxold_use');
  /* wpick 同理：新 key 不存在才從 tbxold_wpick 轉 ids */
}catch(e){} }
```

為什麼用「取大」：兩台裝置手上的舊資料大多一樣（都從同一份雲端拉來）。A 先遷、B 拉到 A 的結果後再遷自己那份，用加總會變兩倍；取大就不會（模擬第 5 項）。代價：兩台在遷移前各自累積、互相沒同步到的次數會少算一點（跟 11-25 報告 1-2 是同一個全站限制）。

雲端已經存在的全文：等全部裝置換新版、上傳過一次就會從那一列消失（第二節 D）。Supabase 端有沒有備份／時間點還原會留著舊版 payload：**未查證**。
