# 預錄語音音檔的授權：能不能把 Mac／開源／雲端語音合成的法文音檔放上網站 — 2026-09-21

> 起因：Owen 的 iPhone 上，網頁語音 API 只給 `Amélie super-compact` 與 `Thomas compact`（最低音質）。
> 查證結論：iOS 不讓網頁用另外下載的高音質聲音（Apple 工程師 2023-01 在開發者論壇明說「只有預先安裝的聲音可用」，
> 來源 [Apple 論壇 thread 723503](https://developer.apple.com/forums/thread/723503)；沒有官方繞法）。
> Owen 決定走「預錄音檔」，並要求先查授權。**本篇不是法律意見**，是照條款原文整理的判讀。

## 一、Mac 內建聲音（`say`）——⚠️ 只能私用，⛔ 不能公開放

**原文已讀**（macOS Tahoe 26 軟體授權協議，[Apple 官方 PDF](https://www.apple.com/legal/sla/docs/macOSTahoe.pdf)，第 2 節 F 項「Voices; Live Captions」）：
- 允許：用系統聲音為**自己的原創內容與專案**產生語音，限**個人、非商業**用途。
- 不允許：除此之外的任何製作或使用，條文明列「使用、重製、展示、演出、**錄製、發布、轉散布**」，且明說**不論營利、非營利、「公開分享」或商業情境**都不行。
- 舊版（Sierra、Sequoia）搜尋結果顯示措辭相同，本篇只讀了 Tahoe 26 原文。

**判讀**（非法律意見）：
- ✅ Owen 在自己的 Mac 上用 `say` 產生音檔、只給自己聽 ＝ 條款允許的「個人、非商業」。
- ⛔ 把音檔 commit 進**公開的 GitHub repo／GitHub Pages**（`owenc8964/french_pronounce`）＝「公開分享」，條文明確不允許，⛔ 即使非營利也不行。
- 🟡 放在**要登入才聽得到**的私人空間、只有 Owen 一人使用（跟考試題圖片同一個 Supabase 私人空間做法）：不是「公開」，更接近「個人使用」，但條文有「發布／轉散布」字眼，仍有灰色地帶，這點只能自己承擔判斷。
- 既有先例：`tools/gen_t1_audio.py` 產的 `audio/t1_*.m4a` 現在是 untracked（沒進 git），做法符合這條——⚠️ 之後 commit 時要確認不要被 `git add .` 帶進去。

## 二、開源語音（Piper `fr_FR-siwis-medium`）——授權寬，但上游沒查完

- 模型卡（[rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices/blob/main/fr/fr_FR/siwis/medium/MODEL_CARD)）：資料集 SIWIS，授權 **CC BY 4.0**（要標示來源；模型卡未列其他使用限制），單一女聲、22.05 kHz、medium 品質。
- ⚠️ 模型卡寫明是「從美式英語 lessac 聲音（medium）微調而來」——**上游 lessac 的授權是否約束這個微調模型，我沒有查到，未查證**，公開放之前要補查。
- 引擎本身與輸出音檔的授權關係（Piper 程式碼授權 vs 輸出）也**未查證**。
- 品質為 medium 神經網路語音；實際聽起來比 iOS 的 super-compact 自然多少，⚠️ 沒有實測。

## 三、雲端神經網路語音（Google Cloud TTS 等）——品質最好，但要 Owen 開帳號

- 搜尋結果（Google 官方文件與二手整理，**官方條款原文未讀全文**）：產出的音檔可用在你自己的應用程式或媒體，須遵守 Google Cloud 條款；二手來源提到「逐次產生給單一使用者」被涵蓋、「重新包裝成媒體庫」不涵蓋。
- 免費額度（二手整理，數字**未核對官方頁**）：WaveNet 約每月 100 萬字元免費、標準聲音約 400 萬；304 句約 1 萬字元量級，遠低於額度。
- ⛔ 需要 Owen 自己建立 Google Cloud 帳號、綁付款方式、產生金鑰——這些我不能代辦（建帳號、輸入金鑰／付款資料是禁止項目）。

## 四、這對設計的決定

1. **先走「Mac 高音質聲音 → 私人空間」**：音檔只放 Owen 自己的登入後私人空間（沿用考試題圖片的 Supabase 私人空間與登入），⛔ **絕不 commit 進公開 repo**。遊戲的 `say()` 先找私人音檔，找不到或沒登入就退回手機內建語音（不報錯）。
2. **`.gitignore` 加音檔資料夾**（例如 `audio/sent/`），避免 `git add .` 誤帶——這是這條路的關鍵防呆。
3. 若想要能公開、也想更自然：Piper 是候選，但**要先補查 lessac 上游授權**與實際音質；雲端神經語音最自然，但要 Owen 自己開帳號。
4. ⛔ 音檔只做**句庫 304 句**先試，不一次做 2353 張卡；試聽通過再擴。

## 五、還沒回答的問題

1. Piper siwis 微調自 lessac，上游授權是否約束下游——未查證。
2. Google Cloud TTS 官方條款原文（Service Specific Terms）沒讀，「重新包裝成媒體庫」的界線只有二手轉述。
3. 私人空間＋登入算不算「個人、非商業」——條文有「發布／轉散布」字眼，屬灰色地帶，非法律意見。
4. Mac 上實際有沒有 Amélie／Thomas 的 Premium 聲音、`say` 產出的音質——沒實測（這個排程 session 不能跑 `say`）。
5. 各方案音檔對 Owen 的耳朵「夠不夠自然」——只能他自己試聽。
