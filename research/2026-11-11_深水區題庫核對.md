## 二、講話人切行（✗ 主要問題）

### 根因（已對照逐字稿原文）
`didier_passage.py` 的 `lines_of()` 用這條 regex 切講話人：

```python
re.split(r"\s*([A-ZÀ-Ý][a-zà-ÿ]+(?: [a-zà-ÿ']+)?(?: \d)?)\s*:\s*", ' ' + text)
```

它只認「一個大寫字（＋可選一個小寫字）」，所以：

1. **「名 姓 :」只抓到姓，名字掉到上一句尾巴**。逐字稿原文是 `Sophie Davant : …`、`Juliette Armanet :…`（p.197），切完變成講話人「Davant」，而「Sophie」被黏在上一個人的話最後，句子切開後就成了**單獨一行「Sophie」**，在 📜 整段原文裡顯示成「Armanet：Sophie」。
2. **連字號姓氏斷一半**：`Danila Sauvain-Kloetzli :` → 講話人「Kloetzli」，上一行尾巴留「Danila Sauvain-」。
3. **正文裡的冒號被當成講話人**（這是 11-10 新加的「大寫＋小寫字」造成的，舊 regex 不會）：t4 `…dans le Jura bernois : l'installation…` → 冒出講話人「Jura bernois」，Voix off 那句停在「dans le」。
4. **三個字以上的角色名抓不到**：t14 `Le responsable du magasin : Les équipes…`（p.199）沒切開，整段被算成「Caissière 3」說的。
5. **出處行被當台詞**：每段最後一行「(RFI, 29/05/2022)」之類。

### 改法提案（改 `tools/didier_passage.py`，重跑 `--upload`；未實測）
1. 講話人分兩種認：
   - **人名**：1–3 個大寫開頭的字（可含連字號、可跨行），後面緊接「:」——`Sophie Davant`、`Danila Sauvain-Kloetzli`、`Caissière 1`、`Homme 2` 都吃得到；`Jura bernois`（第二字小寫）不會被吃。
   - **角色**：`Le|La|Un|Une|Voix` 開頭＋1–3 個小寫字，**而且要在原文行首**（先切講話人、再把換行壓成空白）——`La journaliste`、`Voix off`、`Le responsable du magasin` 吃得到；`Conseil suivant`、`Il dit` 不會被吃。
   - 草稿：`(?:^|\n)\s*((?:Le|La|Un|Une|Voix)(?: [a-zà-ÿ'’]+){1,3}(?: \d)?)\s*:` 與 `((?:[A-ZÀ-Ý][\wà-ÿ'’-]*[ \n]){0,2}[A-ZÀ-Ý][\wà-ÿ'’-]*(?: \d)?)\s*:`
   - 保險：候選名字在同一軌出現 ≥ 2 次，或出現在行首，才算講話人（避免「…à Paris : …」被當成人）。
2. `turns[0]` 不要丟：有文字就收成 `spk=''` 的台詞。
3. 最後一行是 `(媒體, 日期)` → 不當台詞，改放 `P.src` 或直接略過。
4. 重跑後用 `node tools/q46_verify.js` 看 spk 清單是否歸零、`node tools/q46_coverage.js` 看 t64／t68 是否回到 90% 以上。
