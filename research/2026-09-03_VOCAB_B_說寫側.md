## 0. 結論（先看這段）

**要考到 B2，實際「必須產出得出來」的時態只有 4 個半：**

| 等級 | 時態 | 佔全部動詞形 | 為什麼 |
|---|---|---:|---|
| 🔴 沒有就不能開口 | **présent** | 41.9% | 全部三個任務的預設時態 |
| 🔴 沒有就不能開口 | **infinitif**（接在 pouvoir / permettre de / il est important de 之後） | 35.3% | 論述句幾乎都是「定式動詞＋原形」這個骨架 |
| 🟠 特定任務要 | **passé composé** | 4.8% | 只在「寫作 Tâche 2 申訴信」與「口說講自己的經驗」爆量 |
| 🟠 特定任務要 | **conditionnel présent** | 2.6% | 幾乎只是禮貌用語：`je voudrais / j'aimerais / on pourrait / ce serait` |
| 🟡 半個 | **imparfait** | 1.9% | 只需要 `était / avait / voulais`；真正的「過去描述」用量極低 |
| 🟡 半個 | **futur simple** | 1.8% | 只需要 `aura / sera / pourra`；口說 T3 幾乎用不到 |

**présent ＋ infinitif 兩個就佔了 77.2%。** 加上 passé composé、conditionnel、imparfait、futur simple，六個涵蓋 88.3%。
剩下 11.7% 是分詞／被動／gérondif／subjonctif 等**不必主動組裝**的東西。

**⛔ 明確不需要「會產出」的：** plus-que-parfait（0.07%）、conditionnel passé（0.04%）、futur antérieur（0.09%）、passé simple（≈0，全語料只有 2 個，且都疑似誤判）。這幾個只需要**讀得懂**。

### subjonctif 的答案：要，但只是 8 個字，不是一套系統

- 全語料 **124 個** 形態上可確認的 subjonctif présent＝**全部動詞形的 0.8%**。
- **79% 集中在兩個動詞**：`être`（soit 48、soient 7）＋`pouvoir`（puisse 23、puissent 10、puissions 3、puisses 3、puissiez 1）。
- 觸發位置也高度集中：**bien que(48)、pour que / afin que(34)、que ce soit…(18)、il faut que(4)、avant que(4)、jusqu'à ce que(1)**。
- **`il est important que` / `je ne pense pas que` / `il est possible que` 在全語料 = 0 次。** 中國補習班教的範文一律改用 `il est important **de** + 原形`，繞開 subjonctif。

👉 **給 Owen 的處方：subjonctif 不用當一個文法單元學。** 背成 8 個固定塊就好：
`bien que ce soit`／`bien qu'il soit`／`pour que je puisse`／`pour que nous puissions`／`afin que je puisse`／`il faut que je fasse`／`que ce soit A ou B`／`sans qu'il y ait`。
其餘（-er 動詞的 subjonctif、subjonctif passé）**只需要認得**。
⚠️ 誠實聲明：這個 124 是**低估**——`que je parle` 這種 -er 動詞的 subjonctif 跟 présent 同形，程式抓不到。但「觸發詞」的統計不受影響，而觸發詞只有那 6 個，所以結論不變。

### 口說 vs 寫作：最重要的一句話

**差別主要不是語體，是任務。** 同一個議題（T3 論述），口說稿和寫作範文的**內容詞幾乎一樣**，差的是外殼：

| | 口說 T3（每萬詞） | 寫作 T3（每萬詞） |
|---|---|---|
| `je pense que` | **20.0** | **0.0** |
| `personnellement` | 15.4 | 2.7 |
| `à mon avis` | 6.4 | 0.0 |
| `par exemple` | **34.0** | **1.3** |
| `mais` | **38.6** | 2.7 |
| `en effet` | 4.1 | **38.8** |
| `il est essentiel de` | 3.8 | **41.5** |
| `tandis que` | 2.6 | **40.2** |
| `certains pensent/estiment/soutiennent…` | 3.8 | **25.4** |
| `la question de X suscite un débat` | 0.0 | **24.1** |

👉 **口說＝第一人稱＋舉例＋mais；寫作＝無人稱框架＋tandis que 對比＋en effet 補證。**
但真正把兩邊拉開的其實是**另外兩個任務**：

- **口說 Tâche 2 ＝ 問問題機器**（不是講話）：`est-ce que` 159/萬、`quel(le)(s)` 184/萬、`y a-t-il` 102/萬、倒裝疑問 286/萬。這些在寫作語料裡幾乎 0。
- **寫作 Tâche 1 ＝ 書信公式**：`J'espère que tu vas bien` 25/萬、`À bientôt` 23/萬、`n'hésite pas à` 15/萬、`J'ai hâte de` 12/萬、`Je suis ravi(e) de` 11/萬、`Amicalement/Cordialement` 13/萬。這些在口說語料裡 = 0。

所以「該練哪個版本」的答案是：**兩個都要，但它們住在不同任務裡，不要混在同一組卡片。**

### 1.1 一句話讀懂這張表：時態是**綁在任務上**的，不是綁在「等級」上

- **口說 T3（論述）＝ présent + infinitif 佔 86%。** passé composé 3.2%、imparfait 1.4%、futur simple 0.4%、impératif 0.07%。
  你在辯論「單身能不能幸福」時，幾乎不需要任何過去或未來。
- **寫作 T3（論述）＝ 一樣是 présent + infinitif（77%）**，但多了 participe présent（61‰）與 gérondif（38‰）——
  `en imposant une tenue commune`、`créant ainsi un cadre propice`、`favorisant la collaboration`。這是書面體才有的壓縮手法。
  ⚠️ 這批範文只有 40 篇同一來源，句式高度模板化，這個數字**不能當「書面法文通則」**。
- **寫作 T2（申訴信／正式信）＝ 唯一的過去式現場：passé composé 244‰、imparfait 80‰**，présent 反而掉到 227‰。
  你要投訴一趟旅行，就得敘述「我訂了→他們承諾→實際上卻→我不得不」。
- **寫作 T1（給朋友的訊息）＝ 唯一的未來現場：futur simple 48‰、futur proche 10‰、conditionnel 43‰。**
  邀請與資訊提供本質上都是講「接下來會怎樣」。
- **口說 T2（問問題）＝ 唯一的命令式現場（23‰）＋ 疑問句機器。**

### 1.2 更省力的事實：每個「非現在式」時態其實只靠幾個動詞

| 時態 | 實際出現的形式（前幾名） | 前 5 名佔該時態 |
|---|---|---:|
| **conditionnel présent**（420 個） | pourrait(71)、aimerais(66)、serait(37)、pourrais(26)、pourrions(25)、serais(20)、devraient(18)、pourriez(17) | **54%** |
| **imparfait**（316 個） | était(91)、voulais(42)、étaient(34)、avait(26)、étais(12) | **65%** |
| **futur simple**（284 個） | aura(46)、sera(23)、pourras(16)、aurons(13)、pourrons(13)、déroulera(10)、seront(10) | 39% |
| **passé composé**（739 個，涵蓋 169 個動詞） | 助動詞集中在 avoir；最常見的動詞：être(69)、avoir(38)、commencer(22)、permettre(21)、devenir(20)、trouver(19)、prévoir(16)、passer(15)、décider(14)、apprendre(13)。⚠️ 原始數 739 中有 44 個是 `j'ai hâte` 的誤判，扣掉後約 695 | — |

👉 這代表：**conditionnel 不用學一整套變位。** 語料裡 54% 是 `pouvoir` 和 `aimer` 兩個動詞的 conditionnel。
把 `je voudrais / j'aimerais / on pourrait / ce serait / il faudrait` 當成 5 個**詞彙塊**背，就吃掉一半以上。
imparfait 同理：`c'était / il y avait / ils étaient / je voulais` 四塊吃掉三分之二。

⚠️ 誠實補充：`je voulais te remercier`、`je voulais te parler` 這類的 `voulais`（42 次）是**禮貌用的 imparfait**，
不是「過去發生的事」。所以「真正敘述過去」的 imparfait 比 1.9% 還更低。

## 2. subjonctif 專章

### 2.1 出現量

- 形態上**可確認**的 subjonctif présent：**124 個 / 15,308 個動詞形 = 0.81%**
- 分佈：口說 7.5‰、寫作 8.9‰ — **兩邊差不多，沒有「寫作比較需要 subjonctif」這回事**

### 2.2 集中在哪些字

| 動詞 | 次數 | 出現的形式 |
|---|---:|---|
| **être** | 58 | soit(48)、soient(7)、soyez(2)、sois(1) |
| **pouvoir** | 40 | puisse(23)、puissent(10)、puissions(3)、puisses(3)、puissiez(1) |
| avoir | 7 | ait(6)、aies(1) |
| savoir | 5 | sache(5) |
| vouloir | 4 | veuilles(4) |
| faire | 3 | fasse(2)、fassent(1) |
| aller / venir / devenir / reconnaître | 各 1–2 | aille、vienne、devienne、reconnaisse |

**être ＋ pouvoir ＝ 98/124 ＝ 79%。**

### 2.3 出現在什麼位置（左側觸發詞）

| 觸發詞 | 全文出現次數 | 說明 |
|---|---:|---|
| **bien que** | 48 | 口說 44、寫作 4 — 這是口說 T3 讓步段的招牌句 |
| **pour que / afin que** | 34 | 寫作 T1 最多（`pour que je puisse organiser…`） |
| **que ce soit（… ou …）** | 18 | 固定塊，不是活的文法 |
| avant que | 4 | |
| il faut que | 4 | |
| quoique / de sorte que / jusqu'à ce que | 各 1–2 | |
| **il est important / essentiel / possible que** | **0** | 全部改寫成 `il est important **de** + 原形` |
| **je ne pense pas que / je doute que / il semble que** | **0** | 完全不用 |

### 2.4 結論

> **要會產出的 subjonctif ＝ 6 個連接詞 × 8 個動詞形。**
> `soit / soient`、`puisse / puissions / puissent`、`ait`、`fasse`、`aille`
> 放進 `bien que`、`pour que`、`afin que`、`avant que`、`il faut que`、`que ce soit … ou …`。
>
> **不要**把 subjonctif 當成「A2 之後的下一個文法關卡」去系統性攻。
> 考生的真實策略是**繞過去**：需要 subjonctif 的地方，全部改寫成 `il est + 形容詞 + de + 原形`。
> 這個「繞過去」本身就是一個該教的解題方法（依 memory `feedback_exam_strategy_is_content`，解題方法也是教材）。

⚠️ **這一節的已知低估**：`que je parle` 這種 -er 動詞的 subjonctif 與 présent 同形，程式無法分辨，所以 124 這個數字偏低。
但第 2.3 節是**用觸發詞的文字出現次數**算的，不受形態同形影響——而觸發詞只有那 6 個，所以「只需要 6 個連接詞」的結論站得住。

### 3.2 對 `verbs_full.js` 的具體建議

現有 25 個動詞覆蓋產出語料的 **37.8%**。要往上抬，優先補的不是「更多不規則動詞」，而是**這批論述動詞**：

- **第一批（論述引擎，8 個）**：`permettre`（271，第 5 名！）、`penser`（173）、`trouver`（137）、`proposer`（111）、`rendre`（104）、`aider`（106）、`donner`（106）、`offrir`（160）
  → 這些幾乎都是規則 -er 動詞，變位不難，但**它們決定你能不能造出論述句**。`permettre de + 原形` 一個結構就撐起整個 T3。
- **第二批（高頻不規則，補完 CORE）**：`vivre`（148）、`découvrir`（110）、`apprendre`（117）、`comprendre`（63）、`choisir`（59）、`suivre`（40）、`ouvrir`（40）、`obtenir`（34）、`résoudre`（21）、`acquérir`（22）、`nuire`（20）、`promouvoir`（15）、`percevoir`（15）、`convenir`（14）
  → 呼應 memory `project_irregulars_are_the_bottleneck`：`savoir`/`voir` 已經在 25 個裡了，但 `vivre`/`découvrir`/`résoudre`/`acquérir` 這些不規則字根還沒有。
- **第三批（書信／口說任務專用）**：`espérer`（147，寫作 T1 145 次）、`souhaiter`（43）、`hésiter`（48）、`recommander`（47）、`inviter`（38）、`réserver`（48）、`contacter`（36）、`confirmer`（16）
  → 這批只在寫作 T1／口說 T2 出現，但在那裡是必用。

⚠️ 注意：`espérer` / `préférer` / `célébrer` 是 é→è 交替動詞（`j'espère` 但 `nous espérons`），
`appeler` / `jeter` 是重複子音，`acheter` / `mener` 是 e→è。這幾類**規則但會變**的動詞在語料裡出現頻率不低，
比背 20 個罕見不規則動詞更值得放進 `verbs_full.js`。

### 4.1 這 380 個字的形狀（給教材設計用）

用眼睛掃過去，這批「缺口字」不是雜亂的，它們有清楚的四群：

1. **論述評價形容詞**：essentiel、crucial、bénéfique、précieux、efficace、durable、excessif、fondamental、raisonnable、abordable、supplémentaire、régulier、élevé、équilibré
   → 這群是 T3 的評分點。`il est essentiel de` 在寫作範文裡 41.5/萬。
2. **抽象名詞（-tion / -té / -ment / -ance）**：opportunité、compétence、épanouissement、apprentissage、productivité、créativité、diversité、autonomie、responsabilité、dépendance、augmentation、réduction、amélioration、intégration
   → 這群讓句子從「小孩用手機不好」升到「l'usage excessif du portable nuit à la concentration」。**這是 A2 → B2 的實際落差所在**，不是文法。
3. **因果／影響動詞**：réduire、améliorer、favoriser、contribuer（à）、encourager、renforcer、limiter、faciliter、stimuler、nuire（à）、entraîner、causer、susciter、inciter（à）、affecter、garantir、préserver
   → 這群幾乎都是「X 動詞 Y」的兩空格模板，適合做壓縮練習（同結構高頻連發）。
4. **任務專用**：
   - 寫作 T1：hâte、ravi、vivement、amicalement、convivial、mémorable、spacieux、accueillant、déguster、bientôt、détail、séance
   - 口說 T2：livraison、paiement、trajet、agence、billet、urgence、procédure、véhicule、abordable
   - 口說 T3：affirmation（題目用語 `Êtes-vous d'accord avec cette affirmation ?`）、débat、citoyen、gouvernement、politique

`reste`→`rester`、`pousse`→`pousser`、`conséquent`→`par conséquent`、`travers`→`à travers`、
`serre`→`effet de serre`、`quant`→`quant à`、`sein`→`au sein de`、`afin`→`afin de/que`、`tandis`→`tandis que`、`lors`→`lors de`。

## 5. 口說 vs 寫作：完整對照

### 5.1 兩件事要先分開

這批語料的「口說 vs 寫作」差異，**大部分來自任務不同，不是語體不同**：

| | 口說語料的組成 | 寫作語料的組成 |
|---|---|---|
| | T2 = 向對方**提問**（角色扮演）<br>T3 = 議題**論述** | T1 = 給朋友的**訊息／邀請**（24k 詞，佔 64%）<br>T2 = **正式申訴信**<br>T3 = 議題**論述** |

所以像「口說多 `combien`、寫作多 `bientôt`」這種差異，是任務造成的，不是「口語 vs 書面」。
**唯一可以乾淨比較語體的，是 T3 對 T3**（同樣是論述同樣的議題）。

### 5.2 T3 對 T3：同一個意思，兩種說法

| 功能 | 口說 T3 用 | 寫作 T3 用 |
|---|---|---|
| 開場「這是個熱門議題」 | `C'est un sujet très discuté dans notre société, sur internet, sur les réseaux sociaux…`（7.5/萬） | `La question de X suscite un débat passionné dans notre société.`（24.1/萬，口說 0） |
| 引入兩方立場 | `Certains pensent que…, mais moi je pense que…` | `Certains estiment que…, tandis que d'autres soutiennent que…`（tandis que 40.2/萬 vs 口說 2.6） |
| 表達自己立場 | **`je pense que`（20.0/萬）、`personnellement`（15.4）、`à mon avis`（6.4）** | **全部 0。** 改用無人稱：`il est essentiel de…`（41.5/萬）、`il est important de rappeler que…` |
| 補強論點 | `parce que` / `car` / `grâce à` | **`en effet`（38.8/萬 vs 口說 4.1）** |
| 舉例 | **`par exemple`（34.0/萬）** | **幾乎不舉例（1.3/萬）**；改用抽象推論 `ce qui permet de…`、`créant ainsi…` |
| 轉折 | **`mais`（38.6/萬）** | `cependant`、`en revanche`、`de surcroît`(16.1/萬，口說 0) |
| 結尾 | `En conclusion, …`（20.3/萬） | `ainsi`（34.8/萬）收束，或直接停在最後一個論點 |

### 8.3 時態怎麼判的

- lemma 與詞性用 spaCy `fr_core_news_md`。
- **⛔ 沒有直接用 spaCy 的時態標記** —— 實測它把 `nous irions`（conditionnel）標成 `Tense=Imp|Mood=Ind`，把 `fassions`（subjonctif）漏掉。法文模型在 conditionnel/subjonctif 上不可靠。
- 自己寫的規則：
  1. **複合時態** = 定式 `avoir`/`être` ＋ 過去分詞（往前找 4 個 token，遇句號停）。依助動詞的形態分 passé composé / plus-que-parfait / conditionnel passé / futur antérieur / subjonctif passé。`être` + 分詞再依「是不是 ETRE 動詞或反身」分 passé composé vs 被動。
  2. **futur / conditionnel** = 先由 lemma 算出「futur 詞幹」（`-er`/`-ir`→原形、`-re`→去 e、40 個不規則另表），再檢查 `詞形 = 詞幹 + 字尾`。
     這一步是關鍵：`préparait` 去掉 `ait` 剩 `prépar` ≠ futur 詞幹 `préparer` → 判 imparfait；`préparerait` 去掉 `ait` 剩 `préparer` = 詞幹 → 判 conditionnel。
  3. **imparfait** = 上一步沒中、且字尾是 `ais/ait/ions/iez/aient`。
  4. **subjonctif** = 只認**形態上唯一**的 60 幾個形（soit/puisse/fasse/aille/sache/ait/…）。同形的（-er 動詞）放棄，改用觸發詞的文字次數另外統計。
  5. **futur proche** = 現在式 `aller` + 4 token 內的原形；**passé récent** = `venir de` + 原形。
  6. 其餘定式 → présent。

### 8.4 誤判率

**人工抽驗 120 個隨機標記**，逐條看上下文，錯 6–8 個（**約 5–7%**）。錯誤類型：

| 錯誤 | 例 | 影響 |
|---|---|---|
| `être` + 形容詞被算成被動 | `je suis ravi(e)`、`je suis sûre` | 只影響 `être+PP(passif/état)` 那一格（2.1%），該格內部誤判可能高達 30–50% |
| spaCy POS 錯 | `vous recommandez` 被標成 infinitif、`tu utilises` 被標成過去分詞 | 散在各格，~2% |
| 助動詞被連字號吃掉 | `as-tu fait` 沒接上 → 算成單獨過去分詞 | 少量低估 passé composé |
| `j'ai hâte` 被當成 passé composé | `hâte` 被標成過去分詞 | **passé composé 739 個裡有 44 個是這個**（6%）→ 實際 PC ≈ 695 |
| OCR 殘字 | `bient`（bientôt 修復前）、`32train` | 已修掉大部分 |
| `futur antérieur`(14) / `passé simple`(2) | `tous seront compris` 其實是被動未來式 | 這兩格 n 太小，別引用 |

**可以放心引用的**：présent、infinitif、passé composé（扣掉 hâte 後）、conditionnel présent、imparfait、futur simple、subjonctif présent 的**相對大小關係**。
**不要引用**：小於 50 個的任何一格的絕對數字。
