# 專題：高手怎麼學會的（第二輪）——學習力、輸入、輸出

> 2026-10-12。Owen：「『高手是怎麼學會的』可以做更多的研究，要看更多高手，或更深入探討都行。這是一個專題，可以協助法文學得好，但更多的是**提升學習力**，以及**輸入＋輸出**。」
> 第一輪（Musk 為主、七件事）在 [2026-10-12_高手怎麼學會的.md](2026-10-12_高手怎麼學會的.md)。這一輪往兩個方向加深：**看更多高手**、**往下挖機制**。

---

## 先講結論（一頁版）

1. **十位高手的做法，攤開來看幾乎都是同一個迴圈**：
   **大量有興趣的輸入 → 自己產出 → 拿去對照標準 → 改正 → 把改好的版本變成自己的 → 再輸入**。
   富蘭克林練寫作、施里曼學十幾種語言、費曼準備考試，骨架都是這個。差別只在「對照的標準」是什麼（原文、老師、自己的解釋講不講得通）。
2. **輸入和輸出不能互相取代**：研究發現「以理解為主」的練習讓**聽讀**進步比較快，「以產出為主」的練習讓**說寫**記得比較久。**練什麼，長什麼**。
3. **學習力本身可以練，但效果是中等**：教大學生「規劃 → 監控 → 檢討」自己學習的課程，統合分析效果 g≈0.38。反過來，「成長心態」這類信念介入，對成績的效果小到幾乎看不到。
   ⇒ **學習力＝做法，不是心態**。
4. 對你最有用的三個新做法（下面第四部分詳細）：**富蘭克林重建法**（練寫作）、**施里曼迴圈**（寫 → 被改 → 背 → 說出來，你的「語言島」其實就是它）、**「我還說不清楚」筆記本**（費曼）。

## 第一部分：十位高手實際怎麼學

> 可信度標記：🟢 有本人第一手文字＋多方一致｜🟡 主要是本人自述或單一來源｜🔴 二手傳聞。
> ⚠️ 名人的方法都是**倖存者**的說法；這裡只當「線索」，第二部分再拿研究去驗。

| 高手 | 他實際做了什麼 | 背後的機制 | 可信度 |
|---|---|---|---|
| **Elon Musk**（火箭） | 讀火箭教科書讀到能整段引用；同時把最懂推進的專家找進團隊；「知識是一棵樹，先懂樹幹再碰樹葉」 | 先建骨架、向專家學 | 🟡 主要來自同事 Cantrell 的回憶 |
| **富蘭克林**（寫作） | 讀一篇喜歡的文章 → 每句只記一個提示 → **隔幾天不看原文，照提示重寫** → 跟原文對照、找出差在哪 → 改正。字彙不夠就把文章改寫成詩、忘了再改回散文；結構不好就把提示打亂，幾週後重排順序 | 產出 → 對照標準 → 修正；**提取＋間隔＋回饋**全在裡面 | 🟢 他自傳裡寫得很清楚，現在的寫作教學叫「文本重建」 |
| **施里曼**（學了十幾種語言） | 大聲讀很多、不翻譯；每天上一堂課；**寫自己有興趣的主題 → 老師改 → 把改好的版本背起來 → 下一堂課說出來**；他自承記憶力原本很差，「每一刻都拿來用」 | 輸入＋產出＋回饋＋**把正確版本變成口說存貨** | 🟡 本人自傳；學習速度的說法沒人驗證過 |
| **Lomb Kató**（匈牙利口譯，16–17 種語言） | **找一本自己真的想知道結局的小說**，一開始就讀；幾乎不查字典，看不懂就往下讀，重要的字會一再出現、自己解釋自己；在書邊寫下自己理解的意思、反覆讀。她的公式：「**投入時間 ＋ 有興趣 ＝ 成果**」 | 大量、有趣、可理解的輸入；從上下文推字義 | 🟢 本人著作（但細節不多） |
| **費曼**（物理） | 準備博士資格考時，開一本新筆記本，標題寫「**我不知道的東西**」，花幾週把每一門物理拆開、重組，專找邊緣和矛盾 | 主動找缺口；用自己的話重建 | 🟢 Gleick 傳記；⚠️「費曼學習法四步驟」是後人整理的，不是他本人說的 |
| **Waitzkin**（西洋棋冠軍→太極推手冠軍） | 「**把圈畫小**」：把一個技巧練到最深，再把外在動作越縮越小、保留內在力道；深度優先於廣度 | 先練透少數核心，再壓縮成直覺 | 🟡 本人著作 |
| **超級多語者**（Erard《Babel No More》訪問的一群人） | 方法各不相同（有人用字卡、有人純苦練），但**大量重複＋專攻最難的部分**（阿拉伯文的動詞、斯瓦希里語的前綴）是共通的；學到第五種左右之後，開始看懂「語言系統」本身，後面的語言變快 | 刻意練習＋遷移；也有互相干擾 | 🟡 訪談與問卷；大腦證據只有個案 |
| **西洋棋高手**（Chase & Simon 研究） | 能記住整盤棋，不是記憶力比較好，而是把棋子看成**有意義的一塊一塊**；換成隨機擺的棋盤，優勢就消失 | 專家的「塊」＝骨架 | 🟢 經典實驗、多次複製 |
| **十年寫作者／音樂家**（刻意練習研究） | 長期、有結構、專練弱點、有回饋的練習 | 刻意練習 | 🟢 但效果大小有爭議（見第二部分） |
| **成年才學、最後接近母語的人**（多篇研究） | 天分（工作記憶、語音記憶、抓規律的能力）＋高動機＋**大量接觸**；自述裡反覆出現：**很在意發音**、策略性地努力、覺得「這個語言是我的」 | 天分會補償年紀，但投入同樣重要 | 🟢 研究，但樣本少 |

### 十個人的共同點（這才是重點）
1. **都有「產出 → 對照 → 修正」的迴圈**：富蘭克林對照原文、施里曼給老師改、費曼對照「講不講得通」。**沒有人只靠輸入或只靠讀規則變強**。
2. **輸入都是自己有興趣的東西**：Lomb 的小說、施里曼「有興趣的主題」、Musk 想造的火箭。
3. **都先抓核心，再擴張**：Musk 的樹幹、Waitzkin 的小圈、費曼的「本質」、棋手的「塊」。
4. **都主動去找自己不會的**，而不是複習已經會的：費曼的筆記本、多語者專攻最難的部分。
5. **都花了大量時間，而且是零碎時間也用**：施里曼「偷時間來讀」、Lomb 的「時間 ＋ 興趣」。

## 第二部分：輸入、輸出、回饋——研究怎麼說

### 2.1 輸入：要大量，但它不是全部
- **大量閱讀**（自己挑書、讀很多）的統合分析：效果小到中等。早期估計 d≈0.55，**校正掉選擇偏誤之後是 0.37**。閱讀速度進步最多，詞彙最少。
- **讀、聽、看影片學到的生字一樣多**（同一部紀錄片三種方式比較），一週後還記得；**原本詞彙量越大，學到越多**（越有底子，學越快——又是骨架效應）。
- 常聽到的「要懂 95–98% 的字才讀得下去」：⚠️ 這次只查到二手引用，原始論文還沒驗證。
- ⇒ Lomb 的做法（有趣的內容、不中斷、讓字自己重複出現）跟研究方向一致；但**光靠輸入，說和寫不會自己長出來**（見 2.2）。

### 2.2 輸出：它做的是輸入做不到的事
- **Swain 的「產出假說」**：自己說或寫的時候，才會**發現「我想講但講不出來」的缺口**，然後回頭去輸入裡找答案。研究結果有正有反（⚠️ 而且大多是寫作，口說研究比較少）。
- ⭐⭐ **最直接回答「輸入＋輸出」的研究**（Shintani、Li、Ellis 2013 統合分析）：
  - 以理解為主的教法，讓**立刻的聽讀測驗**進步比較多；
  - 以產出為主的教法，在**延後的說寫測驗**上贏；
  - 兩種都有大效果。
  ⇒ **練什麼長什麼，兩邊都要**。考試四科是聽、讀、說、寫，各佔四分之一，不能只練其中一邊。
- 這也跟第一輪講的「練習越像考試，考試越好」是同一件事。

### 2.3 回饋：有用，但要對準
- 課堂口語糾正的統合分析（15 個研究、827 人）：糾正**有顯著而且持久的效果**。⚠️ 有研究整理說「提示學生自己改」比「老師直接重講正確版本」效果大，這點還要回原文確認。
- 回饋有三分之一會讓表現變差（第一輪提過）：關鍵在**指向任務，不要指向人**。

### 2.4 從「知道」到「自動」：這正是你的瓶頸
- 技能習得理論（DeKeyser）：語言能力分三個階段——**知道規則 → 靠規則慢慢做 → 不用想就做出來**。中間那一段只能靠「一邊用一邊暫時扶著規則」的練習推過去。
- 這跟專案裡的教學原則一模一樣：**你的瓶頸多半不是「不知道」，是「還需要想」**。研究上，這一段要的是**同一個結構、在真實使用中、重複很多次**，不是再聽一次規則。

### 2.5 明講規則 vs 讓你自己悟
- 統合分析（Norris & Ortega 2000，以及 Goo 等人後來加了 23 個新研究的重做）：**明講規則的教法比讓學習者自己悟更有效**，而且效果持久。
- ⇒ 你現在「上課學規則＋做筆記」的方向是對的；缺的是後面那段「用到自動」。

## 第三部分：「學習力」本身能練嗎？

| 做法 | 證據 | 對你的意思 |
|---|---|---|
| **學怎麼學**（規劃 → 監控 → 檢討自己的學習） | 大學生的統合分析：49 個研究、5,786 人，效果 g≈0.38；以「後設認知」為基礎的課程效果比較大 | ✅ 能練，中等效果。具體做法就是：學之前定目標、學的時候知道自己哪裡卡、學完檢討 |
| **成長心態**（相信能力可以變強） | 兩個大型統合分析（約 36 萬人、43 個介入研究）：整體效果很弱（介入約 d≈0.08）；只對弱勢或學業高風險的學生比較有用 | ⛔ 不值得花力氣。**學習力是做法，不是信念** |
| **刻意的困難**（間隔、交錯、自我測驗、變換練習條件） | Bjork：讓「當下」變難、但「之後」記得更牢；⚠️ 前提是你有足夠的底子去克服那個困難 | ✅ 你的系統大多已經有了；注意不要難到卡死（跳過規則就是在防這個） |
| **交錯練習**（不同類型混在一起練） | 59 個研究的統合分析 g=0.42；**最適合「長得很像、容易搞混」的東西**（例如畫風辨認 g=0.67）；⚠️ 語言材料的研究很少 | ✅ 適合 lui／à lui、y／en、imparfait／passé composé 這種「容易搞混的一對」 |
| **運動** | 一次有氧運動對長期記憶 ES≈0.52；**學完之後運動，效果比學之前大**；⚠️ **邊學邊運動反而變差** | ✅ 上完課、讀完新東西 → 走路或運動 10–20 分鐘；⛔ 不要邊跑步邊背單字 |
| **睡眠** | 專案的「離線鞏固」研究已整理：睡前練、隔天早上複測 | ✅ 已有，見 METHOD_MAP 的離線鞏固那一節 |

## 第四部分：給你的框架與做法

### 一個迴圈（從十位高手抽出來的）
```
  有興趣的輸入 ──→ 自己產出（說／寫）──→ 對照標準 ──→ 改正
        ↑                                            │
        └──── 把改好的版本變成自己的（背、說出來）←──┘
```
- **輸入**：自己想知道結局的東西（Lomb）。
- **產出**：寫一段、說一段（施里曼、富蘭克林）。
- **對照**：原文、老師、或「我講不講得通」（富蘭克林、施里曼、費曼）。
- **變成自己的**：把改好的版本背起來、下次說出來（施里曼）。

### 你已經有的 vs 缺的
| 迴圈的一段 | 你已經有 | 缺的 |
|---|---|---|
| 有興趣的輸入 | 今日閱讀（考試原題）、課本 | **為了好玩而讀／聽**的東西幾乎沒有 |
| 產出 | 三連、填表（都是「填一格」） | **完整的一段話**：寫作 0、口說很少 |
| 對照 | 遊戲的對錯、老師上課 | 自己寫的東西**被改過**的經驗很少 |
| 變成自己的 | ⭐ **口說「語言島」——其實就是施里曼的方法**（寫好 → 改正 → 背 → 說） | 只做了口說，**寫作還沒有** |

### 最值得試的三件（都很小，不用蓋新系統）
1. **富蘭克林重建法（練寫作）**：挑課本裡一段你喜歡的對話或短文（真實教材，不用 AI 生）→ 每句寫一個中文提示 → **隔 2–3 天**只看提示寫回法文 → 跟原文對照，圈出差在哪 → 差的地方就是你的下一個練習點。一次 10–15 分鐘、一週一次。
2. **施里曼迴圈（寫作版的語言島）**：寫一小段自己有興趣的主題（5–6 句）→ 給老師或 AI 標出錯（⚠️ 只信它說「這裡怪」，答案要自己查）→ 改正 → 背起來 → 下堂課說出來。這正好補上「寫作 0」那一格。
3. **「我還說不清楚」筆記本（費曼）**：一頁就好，記下「我知道答案、但講不出為什麼」的東西（例如這週的 lui réponds／à lui）。每次上課挑一兩個問老師。⚠️ 這頁是你自己的，不放進課堂筆記。

### 不建議
- ⛔ **只做輸入**，期待口說和寫作自己長出來（研究說不會）。
- ⛔ **只做填一格的題目**，以為那就是輸出（那是練零件，不是練一段話）。
- ⛔ 花時間在心態標語、名人作息上。
