**改法（提案，⛔ 這次沒有改 build.py）**：在 build.py 第 29 行把 `q[txt]` 換成 `clean(q[txt])`：

```python
import re
CJK=re.compile(r'[㐀-鿿＀-￯]')
def clean(s):
    i=s.find('\n–\n')            # 解析都接在這個分隔後面
    if i>=0: s=s[:i]
    assert not CJK.search(s), s[:80]   # 還有中文就停下來，不要默默產生
    return s.rstrip()
```

修完重跑，再 `grep -l '[一-龥]' data/*.js` 確認 0 個，然後重新壓 zip。
