## 1. 法語教材怎麼排變位表 ⭐⭐⭐

### 1-1 本專案課本 Édito（A1 + A2）——【一手實據，直接讀 PDF 抽字檔】

來源：`assets/.textbook_cache.txt`
- Édito A1（`Edito22 A1 Owen.pdf`）p.168「Conjugaisons」附錄
- Édito A2（`Edito22 A2 Owen 7:21.pdf`）p.192「Conjugaisons」附錄

**排版方式：一個動詞一個獨立區塊（block），不是「多動詞併排比較表」。**
每個區塊內部是「一個動詞 × 六個人稱 × 多欄時態（Présent / Impératif / Passé Composé，A2 更多到 Imparfait/Futur/Conditionnel/Subjonctif）」的直式表格。動詞與動詞之間**完全分開、互不共用欄列**。

**動詞出現順序（兩本教材一致）：**
ÊTRE → (FINIR) → AVOIR → (VENIR) → ALLER → (DEVOIR/FAIRE 視版本) → FAIRE → …
A1 p.168 實際排列（因版面關係兩欄並排，但左右欄是兩個各自獨立的動詞區塊，不是同一張表）：
```
ÊTRE          FINIR
AVOIR         VENIR
ALLER         DEVOIR
FAIRE         POUVOIR
PARLER        VOIR
SE LEVER      PRENDRE
```
A2 p.192 排列（單欄，時態更多）：
```
ÊTRE
AVOIR
ALLER
FAIRE
HABITER
SE SOUVENIR
```

**關鍵發現：être/avoir/aller/faire 被放在最前面、彼此緊鄰，但從未合併成同一張「以人稱或動詞為行的比較表」。** 每個動詞永遠保有自己完整、獨立的六人稱區塊。A1 版面上兩欄並排單純是省紙空間（不規則動詞跟規則動詞配對排版），不是刻意做「易混淆組對照」。

沒有找到任何一處把 ils/elles 的四種形式（sont/ont/vont/font）抽出來單獨做一張橫向對照小表。

### 1-2 Bescherelle（法國最權威變位工具書）——【一手實據，WebFetch 官方線上版】＋【廣泛引用】

WebFetch `conjugaison.bescherelle.com/verbes/etre`：
- **一次只呈現一個動詞**，不與其他動詞併排比較
- 版面是「依語氣/時態（直陳式、條件式、虛擬式、命令式、不定式、分詞）分段直式列出六人稱」，不是欄狀對照
- 書面版（紙本 Bescherelle）依網路資料描述：**104 個「模型動詞」each 一張表**，全書用「動詞→對應到哪張表」的索引系統查詢；être/avoir 各自有自己的表，不會被塞進同一張

**結論：Bescherelle 與 Édito 兩個獨立來源（一本教材、一本工具書）在「一動詞一表、不做多動詞比較表」這件事上完全一致。這個一致性本身就是資訊——即使沒有明說理由，這是幾乎全行業共通的排版慣例。**

沒查到 Alter Ego、Le Nouveau Taxi、Grammaire progressive du français 的變位附錄實際版面——搜尋只找到書籍銷售頁與習題本內容，抓不到附錄掃描頁，【查不到】，不推論。

## 2. 補習班／應試班怎麼教最快 ⭐⭐

【廣泛實踐，來自 formation-tcfcanada.com、prepmyfrench.com 等 TCF/TEF 備考網站的公開內容】

- 多處明確指出**不規則動詞沒有通則、必須死背**，優先順序一致提到：**être、avoir、faire、aller、dire** 是「最重要、最優先」的動詞
- 教學策略是「**按家族分組**」而非「按易混淆分組」：例如 venir/tenir/devenir/revenir 同一變化模式歸一組、prendre/comprendre/apprendre 歸一組——這是「同構造」的家族，不是「發音或意義相似」的家族
- PrepMyFrench 頁面用語："Learn the rebel families instead of fighting each verb alone"（學會叛逆家族，別跟每個動詞單打獨鬥）——邏輯是**用構詞規律分組來降低記憶負荷**，跟 Owen 問的「être/avoir/aller/faire 要不要並排」不是同一種分組邏輯
- 建議的操作方法：fiches de conjugaison（單張動詞卡）+ 融入完整句子情境 + flashcards + 線上互動題＋即時批改

**沒查到**任何補習班網站展示實際的「出題畫面/排版」截圖或描述，只查到文字建議，抓不到畫面層級的證據。

## 3. 法語教師社群的實務討論 ⭐

【混合：一處一手實據 + 多處查不到】

- francaisfacile.com 的「être ou avoir - les distinguer」練習頁（WebFetch 成功讀取）：
  **這是一個把 être 和 avoir 混在同一組填空題裡的練習**，例如：
  - "Nous __ un joli parc dans notre quartier."（該填 avoir，表擁有）
  - "Tu __ bien pâle aujourd'hui !"（該填 être，表狀態）
  但⚠️ **這不是「ils sont / ils ont 拼字混淆」的辨識練習，是「語意上要選哪個動詞」的判斷練習**——性質不同，不能直接當作「易混淆組要並排練」的證據，只能說「練習層面確實存在混合出題」

## 4. 學習者社群怎麼自己弄 ⭐

【廣泛實踐，來自 Quizlet 搜尋結果標題，未能讀取卡片內容細節】

搜尋「Quizlet être avoir aller faire」出現至少 10 組不同人／不同課程建立的牌組，標題模式高度一致，例如：
- "être, avoir, aller, faire au présent"
- "Les verbes Avoir, Être, Aller et Faire au présent"
- "Présent: les verbes fondamentaux (être, avoir, aller, venir, faire, pouvoir, vouloir présent)"

**發現：許多獨立的學習者/教師自製牌組，把 être + avoir + aller + faire 四個動詞打包成同一副牌**（而非各自分開建牌）。這跟教材附錄「各自獨立區塊」的排版慣例不同——**學習素材（flashcard 練習用）與參考資料（教材附錄、Bescherelle）在「要不要放一起」這件事上呈現出不同的慣例**：參考資料傾向分開自成一頁方便查找；學習者自製的練習牌組傾向把這四個「核心動詞」捆在一起記憶。

⚠️ 但**沒能讀到牌組內部卡片的實際排列方式**（是「je suis」單卡穿插在「j'ai」之間，還是先練完 être 六人稱才換 avoir）——嘗試 WebFetch 一組牌組內容被 Quizlet 擋下（HTTP 403），【查不到】卡片內部排序，不猜測。

Reddit（r/French、r/learnfrench）搜尋沒有找到直接討論「一次練一個動詞 vs 混著練」的討論串，**查不到**，可能是搜尋詞沒有命中，不代表沒有討論存在。

## 一句話總結（給主對話接手判斷用，不是我的建議）

**參考資料（教材附錄、Bescherelle）的排版慣例一致是「一動詞一獨立區塊」，即使 être/avoir/aller/faire 順序上緊鄰也不合併成對照表；但學習者自製的練習素材（Quizlet 牌組）常把這四個核心動詞打包成同一份學習單位。** 這兩種慣例分屬「查字典/查資料」與「背誦練習」兩種不同使用情境，用途不同，不能直接類推哪個對 Owen 的「表格填空」設計更適用——這是主對話需要自己判斷的地方，不是本次調查能替代決定的。
