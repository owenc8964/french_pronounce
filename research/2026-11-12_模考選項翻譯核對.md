## 一句話結論

**選項中文翻譯本身很可靠**：抽 64 題、256 條翻譯，沒有一條翻錯意思，也沒有一條把錯的選項翻得像正解；只有 5 條措辭可以更精準。
**真正的問題在翻譯以外**：① 有 3 題的法文選項裡混著原始資料的「Correctanswer」字樣，而且黏在**錯的**選項上，作答時就看得到，會直接誤導；② 逐字稿「一句一行」對「句點後沒空白」的地方完全沒切，抽樣 64 題有 39 題有這種黏句，其中不少正好是換人說話的地方（就是 Owen 11-10 回報的那種問題，還沒根治）；③ 約 37% 的題目，「Transcription」區塊後半段混著中文解析和「正確答案是 B」，是原始 PDF 帶進來的。

## 五、逐字稿「一句一行」切得對不對

`reflowFr()`（`mock.html` 第 912–916 行）的做法：先把 PDF 斷行全部接成一行，再在「句末標點 **＋空白** ＋大寫字」處換行。

抽樣 64 題（`node tools/tmp_q49_sample.js 64 --flags`）：

| 情況 | 題數 |
|---|---|
| 完全乾淨 | 17 |
| 有「句點後沒空白」而沒切開的黏句 | 39 |
| Transcription 裡混著中文解析 | 18 |
| 「Question 11.Que fera…」題號跟題目黏一起沒切 | 4 |

（一題可能同時有好幾種，所以加起來超過 64。黏句的判定只抓「標點緊貼下一個字」，像 co_12 Q20「boutique ?Si ça vous dérange」這種問號前有空白、後面沒空白的沒抓到，**實際比 39 題多**。）

全庫：
- **黏句**：744 題、至少 1228 處。原因是原始 PDF 常常寫成「problèmes.Et la FUB」——句點後面沒空白，正則要求 `\s+` 所以不切。
  - ⚠️ 其中不少正好是**換人說話**：co_6 Q19「c'était comment ?Ou on est parti」、co_13 Q20「en retard cette semaine.Je m'excuse」、co_5 Q27「vous parlez, vous ?C'est un français」——跟 Owen 11-10 回報 co_3 Q11「C'est vrai 應該已經換行了」是同一類，修法只修到「有空白」的那一半。
- **混入中文**：476 題（約 37%）。原始資料在「–」那一行之後接了 PDF 的中文解析、選項片段和「正確答案是：B…」，例如 co_7 Q35 Transcription 最後兩行是「– 因此，正確答案是 B.」「Les interventions nécessaires…」；co_11 Q35 最後一行還被截斷成「…a disparu(它設立的主」。這不是 72d06c1 造成的（原資料就有），但現在標題寫「Transcription」，看起來像逐字稿的一部分。這些中文解析在 `script_zh` 裡大多已有（抽看 co_36 Q37、co_12 Q36 是有的；**全部是否都有，未查證**）。
- **單獨一個「–」的行**：584 行（就是上面那個分隔號，什麼都沒有時就孤零零一行）。
- **「M.」後誤切**：約 20 處，例如 co_2 Q16「Je suis M.」／下一行才是名字；co_37 Q13「Pourquoi M.」。（另有 7 處是「etc.」後切行，那是真的句尾，沒問題。）
- **「Question 34.」單獨成一行、題目在下一行**：344 處，不影響理解，可接受。
- **超過 220 字的長行**：451／11947 行，多半就是上面黏句造成的。

### 改法（提案，未執行；改的是 `mock.html` 的顯示函式，不動資料）

```js
function reflowFr(s) {
  let t = String(s || '').split('\n').map(l => l.trim()).filter(Boolean).join(' ');
  t = t.replace(/\s*–\s*[\s\S]*$/, '');                       // ① 「–」之後是 PDF 的中文解析，逐字稿到此為止
  t = t.replace(/([.?!…])\s*(?=[«"A-ZÀ-Ý–—])/g, (m, p, off, all) =>
        /\b(M|Mme|Mlle|Dr|St)\.$/.test(all.slice(Math.max(0, off - 4), off + 1)) ? m : p + '\n');  // ② 句點後沒空白也切，但 M./Mme. 不切
  t = t.replace(/\s*(Question\s*\d+\s*[.:：]?)\s*/g, '\n$1 ');  // ③ 題號換行，題目接在同一行
  return t;
}
```

- ① 會把混入的中文解析與「正確答案是」從 Transcription 拿掉（中文解析仍在下方「翻譯與解析」）。⚠️ 要先確認「–」在某些題不是逐字稿內容裡的破折號（如對話用破折號開頭），**未查證**——可先用 `tools/tmp_q49_stats.js` 加一條「切掉後 CJK 歸零、法文長度沒少太多」來檢查。
- ② 原本的正則也允許在「-」前切，這會在「– 」破折號前切開；①先砍掉就沒差。數字小數（10.5）後面接數字不是大寫，不會被誤切。
