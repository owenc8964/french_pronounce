# 提取練習的題型：選擇題 vs 產出題（填空／中翻法）

> 2026-09-26 清晨排程〔排程提案〕。出自 [`2026-09-16_動態難度調整.md`](2026-09-16_動態難度調整.md)（R3）第五節「還沒回答的問題」第 3 條：
> 「題型組成的『低/中/高三階』比例（例如 70/30 → 50/50 → 30/70）沒有文獻依據」。
> 同時服務佇列裡的 **B10**（09-18 Owen 回饋①：主線一路選「普通攻擊」＝最省力的題型，「問中文答法文單字」太簡單）。
> 要回答：**選擇題本身有沒有練到東西？產出題值多少？兩者該怎麼混？**
> ⚠️ 本篇只查證據，不改程式。讀到全文的：Yang et al. 2021（*Psychological Bulletin*，Table 2 與正文 p.15–17）、Pauwels 2021（*CJAL*，p.98–102）；其餘逐項標讀到什麼程度。

## 一、八個家族掃過一輪（METHOD_MAP.md）

| 家族 | 對「選擇 vs 產出」的立場 |
|---|---|
| **A 刻意練習** | ⭐ 本題主場：練習條件要逼近目標條件（transfer-appropriate processing）；TCF 口說／寫作是**產出** |
| **B 大量可理解輸入** | 辨識（聽讀）靠量；選擇題對「認得」有用，但認得不等於說得出來 |
| **C 策略能力／語言島** | 整塊產出是目標 → 要練「從中文意思叫出整塊法文」，選擇題練不到叫出這一步 |
| **D AI 對話夥伴／回饋** | 產出題答錯後的回饋比選擇題答錯後的回饋更有用（Kang 2007） |
| **E 內容驅動** | 無直接關係 |
| **F 動機工程** | 選擇題答對率高、挫折低 → 是維持「想點進來」的燃料；但玩家會自然偏向它（Bjork 2013：學習者偏好輕鬆、避免犯錯） |
| **G 感知解碼** | 聽辨選擇（`看破`）練的是理解，不是解碼；不在本題範圍 |
| **H 修訂循環** | 無直接關係 |

## 三、關鍵發現

1. **選擇題不是沒用**。課堂統合分析（來源 1）裡辨識型與回憶型效果**一樣大**（0.518 vs 0.520）；Little 2012 顯示好的干擾選項也會觸發提取。⇒ ⛔ **不要把「普通攻擊」拿掉或懲罰它**。
2. ⭐ **真正決定效果的是「練習題型跟最後要用的題型像不像」**：相符 g=0.531 vs 不相符 0.399（來源 1，p<.001；來源 3 方向一致）；L2 研究（來源 8）也是「練哪個方向，那個方向就好」。Owen 的目標考試裡**口說與寫作是 100% 產出**，而且 R17／R26 已經確認遊戲的長期保留要靠後續提取——所以**對 B2 產出能力來說，選擇題是「不相符」題型**。
3. **實驗室研究（來源 2）說回憶型 > 辨識型；課堂研究（來源 1）說兩者一樣**。Yang 等人的解釋：沒有回饋時，辨識題答對多 → 多一次接觸，抵銷了回憶題「比較費力」的好處。⇒ **產出題要搭回饋才吃得到優勢**（Kang 2007：回饋只對簡答題有加成）。quest.html 的產出題答錯會顯示答案（`aNote`），這個條件已經滿足。
4. **選擇題的副作用：錯誤選項會被記住**（來源 5），給回饋能減半（來源 6）。遊戲裡選擇題答錯後有顯示正解，風險已經壓低；但**干擾選項如果是「很像對的錯法文」**（例如陰陽性錯、變位錯），沒有回饋的情況下會種下錯誤形式。
5. **玩家會自然往輕鬆的題型走**（來源 9：Bjork 2013；呼應 memory `feedback_menu_defaults_to_easiest`）——這是 B10 要解的問題，文獻支持「不能只靠文案，要靠結構」。
6. **次數比題型重要**：同一份課堂資料裡，測驗 1 次 g=0.444、≥3 次 0.642（來源 1）。⇒ 一場戰鬥只答 2–4 題（09-18 回饋③）的問題，比題型比例更嚴重。

## 四、跟 quest.html 現況對照（讀程式碼，未執行）

- `pickWeightedQs()`（`quest.html:722`）把 `choose` 和 `gender` 都歸成「辨識型」，但**重擊（gender）的作答方式是打字**（`MOVES.heavy.why`：「錯一個字母就不算」，`quest.html:529`）→ 它其實是**產出型**，分類錯了。影響：tier0 的「70% 辨識」裡有一部分其實是產出題，實際比例比設計的更偏產出。（B 類小修，記給互動 session）
- `普通攻擊` 在 09-20 已改成「拼句（有陷阱）或選擇題」（`quest.html:528`）。**拼句是「有限制的產出」**——要自己排出詞序，但字塊都給了——介於辨識與產出之間。它比純選擇題更接近目標題型，是好的中間層。
- 三階比例 `[[0.7,0.3],[0.5,0.5],[0.3,0.7]]`（`quest.html:723`）：文獻**沒有**給任何具體比例（見第六節第 1 條）。

## 五、這對系統的具體設計決定

1. ⭐ **B6 三階比例的依據改寫成「題型相符原則」，數字暫不動**：文獻支持「越接近考試越要偏產出」的方向，不支持任何具體百分比。現行 70/30→50/50→30/70 **方向正確、數字是約定**；⛔ 不需要再為了找「最佳比例」花研究時間。唯一要修的是 `gender` 的歸類（第四節）。
2. ⭐ **B10 的主軸不是「壓低選擇題」，是「每場戰鬥至少一次產出」＋「題數拉高」**：
   - 每場戰鬥（至少精英與關主）**保證出現 ≥1 題產出型**（填空／中翻法／gender 打字），不靠玩家自選——這是結構，不是文案（來源 9、memory `feedback_menu_defaults_to_easiest`）。
   - 普通攻擊**保留、不扣分、不削弱**（來源 1、7：選擇題本身有效；F 家族：它是低挫折燃料）。
   - 比起調比例，**先把每場的題數拉上來**（1 次→≥3 次提取，g 0.444→0.642）。
3. **產出題一定要有回饋，而且回饋要比選擇題更完整**（來源 3、4）：答錯時顯示正解＋原句，現在已經有；⭐ 答**對**時也短暫顯示正確拼寫——產出題的價值有一部分來自「看到自己打的跟正解對齊」。
4. **拼句（普通攻擊的主力形式）優先於純四選一**：它是有限制的產出，比選擇題更接近目標題型，挫折又比整句中翻法低。B10 若要調普通攻擊內部比例，往拼句傾斜。
5. **選擇題的干擾選項不要用「錯的法文形式」**（例如故意寫錯的變位、錯陰陽性的冠詞）當誘答，除非答完一定顯示正解——否則會種下錯誤形式（來源 5、6）。干擾選項用「別句的中文」或「別的正確法文」比較安全（`listenQuestion()` 現在就是用別句的中文，是對的做法）。
6. ⛔ **不要把「產出題答錯」算得比「選擇題答錯」更重**（例如扣更多角色血量）：產出題本來就比較難，錯誤率高是正常的；再加重懲罰會讓玩家更往選擇題跑，剛好抵銷第 2 點。反過來可以給產出題**更高的傷害／獎勵**（現在 `MOVES` 的 dmg 已經是這樣：hit 1、blast 2、chant 3），方向正確。

## 六、還沒回答的問題

1. **「辨識：產出」的最佳混合比例**：兩篇統合分析都沒有編碼「同一學習者混合題型的比例」這個變項，查無。只能用 Owen 自己的資料看：tier 升降後，產出題正確率與遊戲停留時間怎麼變（R9 量測方案）。
2. **Rowland 2014 全文**沒讀到（EPFL 課程網站有 PDF 連結，本次沒有嘗試讀完）：回憶 vs 辨識的差距在「有回饋」的子群組是否仍然存在——這決定第五節第 3 條的強度。
3. **拼句（詞塊重排）算哪一種提取**：文獻沒有把「給字塊排順序」獨立成一類；它在效果上比較像選擇題還是填空，沒有證據。
4. **L2 語法（不是詞彙、不是事實知識）的題型效果**：本篇所有統合分析的素材以事實知識與詞彙為主；「變位／配合」這種規則性知識的選擇 vs 產出比較，查無。
5. **成人自學、手機、遊戲情境**：來源 1 的課堂 ≠ 單人遊戲；「在遊戲裡被強制產出」會不會降低回訪意願，文獻答不了，要看 Owen 玩過的反應。
